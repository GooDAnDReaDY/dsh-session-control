# @goodandready/dsh-session-control

Управление сессиями в боковой панели DeepSeek Harness: закрепление нужных
диалогов, перенос между проектами, переименование по месту и обратимое скрытие.

> **Статус: в разработке.** Собрана половина «сервис». Интерфейс списка ещё не
> реализован — после установки тело боковой панели будет пустым. Ставить пока
> не нужно.

## Что плагин делает с панелью

Плагин **заменяет тело боковой панели** — блок со списком рабочих папок.
Остальная панель остаётся штатной: бренд, кнопка новой сессии, подвал и вход в
настройки не затрагиваются.

Заменяет, а не дополняет, по устройству ядра: слот `sidebar.workspaces`
объявлен как `kind: "single"`, второго регистранта у него не бывает, а другого
слота в теле панели нет.

## Чем это отличается от штатной панели

| | Штатная панель | С плагином |
|---|---|---|
| Закрепление диалогов | нет | есть, общее на всю панель |
| Переименование | диалогом | по двойному клику в строке |
| Скрыть лишнее | только архив, необратимо | обратимое скрытие |
| Архив | не виден нигде | отдельный свёрнутый раздел |
| Индикатор работающей сессии | не показан | точка в строке |

Штатные возможности — проекты, поиск по содержимому диалогов, ответвление
сессии — остаются на месте: плагин их переиспользует, а не переписывает.

### Чего плагин не умеет и не будет

Переносить диалог в другую рабочую папку. Рабочая папка — это каталог на хосте, а членство сессии выводится из её рабочего каталога: `attachSession` в реестре отвергает сессию, чей `cwd` не совпадает с путём папки. Перенести диалог в другую папку нельзя ни из клиента, ни из серверной половины — это не пробел в API, а устройство модели. Именно поэтому такого пункта нет и в ядровой панели.

## Установка

```bash
dsh plugin --profile web add @goodandready/dsh-session-control
```

## Как вернуть штатную панель

```bash
dsh plugin --profile web remove @goodandready/dsh-session-control
```

Штатный ряд `ui-workspace` включается обратно, панель возвращается к исходному
виду. Закрепления и скрытия остаются в настройках и подхватятся, если плагин
поставить снова.

## Настройки

Карточка в «Настройки → Плагины → Настройки плагинов». Пространство настроек —
`dsh-session-control`, два поля:

| Поле | Смысл |
|---|---|
| `pinned` | закреплённые сессии, порядок массива = порядок в панели |
| `hidden` | скрытые сессии |

Настройки хранятся на хосте, поэтому закрепления переживают перезагрузку, смену
браузера и другое устройство.

## Устройство

Плагин собран из двух независимых половин, и это не украшение архитектуры, а
требование безопасности.

Заменяемый ядровый модуль попутно отдаёт служебный сервис `uiWorkspace`,
который стоит в обязательных зависимостях у модулей боковой панели и интерфейса
беседы. Если его не отдать, приложение не поднимется вовсе.

- **Половина «сервис»** отдаёт `uiWorkspace` и корневой хук списка папок. Без
  React, без логики плагина, без настроек.
- **Половина «интерфейс»** — список сессий и выбор папки на пустом экране
  беседы. Целиком в защитной обёртке.

Отказ интерфейса оставляет тело панели пустым, но панель, настройки и беседа
продолжают работать.

## Совместимость

Разработан под ядро DSH `0.1.2-rc.1`. Плагин опирается на контракт слотов
боковой панели и на поверхность сервиса `uiWorkspace`; при смене этого
контракта в ядре потребуется правка.
