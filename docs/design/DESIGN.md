# DESIGN.md — dsh-session-control

Дизайн-контракт плагина. Источник истины о том, что видит пользователь и почему
именно так. Дополняет спецификацию
`docs/superpowers/specs/2026-09-05-dsh-session-control-design.md`: там — почему
такая архитектура, здесь — как это выглядит и ведёт себя.

## Product / Purpose

- **Назначение:** управление сессиями DSH в боковой панели — закрепление нужных
  диалогов, перенос между проектами, переименование по месту, обратимое
  скрытие, доступ к ядровому архиву.
- **Аудитория:** пользователь DSH, у которого накопилось больше диалогов, чем
  помещается в голове: несколько проектов, десятки сессий, часть из них нужна
  постоянно.
- **Статус:** выпуск `0.2.1`, адаптация под DSH alpha2 (`0.1.6-alpha.2`).

## User Surfaces

- **Web/UI:** тело боковой панели — слот `sidebar.workspaces`. Плагин заменяет
  ядровый блок «Рабочие папки» целиком. Остальная панель (бренд, «Новая
  сессия», подвал, настройки) остаётся ядровой и не затрагивается.
- **DSH UI / settings / slots:**
  - `sidebar.workspaces` (`single`/`root`) — наш список;
  - `conversation.hero.workspace` (`single`/`root`) — выбор папки на пустом
    экране беседы, обязательство замены;
  - дочерние слоты `sidebar.workspaces.directoryFlow` и
    `conversation.hero.workspace.directoryFlow` — объявляем, чтобы работал
    выбор каталога;
  - `settings.plugin.item` с ключом `dsh-session-control` — карточка настроек.
- **API:** три собственных HTTP-маршрута:
  - `GET /dsh-session-control/transcript?session=<id>&format=<json|md>` —
    расшифровка архивной сессии или готовый Markdown для единичной выгрузки.
  - `GET /dsh-session-control/titles?sessions=<id,...>` — выведенные подписи из
    первой фразы человека (до 60 id за запрос, кэш в памяти процесса).
  - `POST /dsh-session-control/export-batch` — пакетный экспорт нескольких
    сессий в структурированный единый Markdown-документ с оглавлением.

  Все остальные действия идут в ядровые `session/rename`, `session/create`,
  `workspace/archiveSession`.
- **CLI:** отсутствует.
- **Документация:** `README.md` (установка, что заменяет, как вернуть штатную
  панель), `CHANGELOG.md`, этот файл, спецификация.

- **Размер и переезд (#39–#41):**
  - `GET /dsh-session-control/sizes?sessions=<id,...>` — число событий, размер
    журнала и уровень значка; только метаданные `sessionPersistence.stat`, журнал
    не распаковывается.
  - `GET /dsh-session-control/handoff` — мгновенная выдержка без модели.
  - `POST /dsh-session-control/handoff-summary` — пересказ моделью; только POST и
    только same-origin, потому что это единственный маршрут, тратящий токены.
  - Слот `conversation.input.dock` (область сессии) — невидимый компонент,
    вставляющий ожидающий черновик через `inputActions.setDraft`.

## Visual Direction

- **Атмосфера:** неотличимо от ядра. Плагин занимает место штатного блока, и
  пользователь не должен замечать подмену — ни по отступам, ни по шрифтам, ни по
  поведению при наведении. Всё новое (закрепление, разделы) выглядит так, будто
  всегда было частью DSH.
- **Утверждённые референсы:** сама ядровая панель DSH — блок «Рабочие папки»,
  строка сессии, меню `...`, карточки настроек «Консоль» и «Цикл агента».
  Берём из них метрики, роли цветов, поведение раскрытия и вид меню.
- **Не копировать:** чужие плагины-переписыватели боковой панели, их разметку,
  классы и ассеты. Референс — принципы ядра, а не чей-либо готовый интерфейс.

## Foundations

### Цвета и роли

Только переменные темы, ни одного литерального цвета. Набор снят с ядровых
модулей панели, а не придуман:

| Переменная | Роль у нас |
|---|---|
| `--dsw-alias-label-primary` | заголовок сессии, название папки |
| `--dsw-alias-label-secondary` | возраст сессии, подписи разделов |
| `--dsw-alias-label-tertiary` | значки, шеврон раскрытия |
| `--dsw-alias-label-caption` | пояснения в пустых состояниях |
| `--dsw-alias-interactive-bg-hover` | подсветка строки при наведении |
| `--dsw-alias-state-business-primary` | активная сессия, индикатор `running` |
| `--dsw-alias-state-error-primary` | ошибка операции в строке |
| `--dsw-alias-border-l2`, `--dsw-alias-border-l4` | разделители, рамка карточки |
| `--dsw-alias-bg-layer-3` | фон карточки настроек |
| `--dsw-specific-sidebar-fill` | фон панели |
| `--dsw-alias-scrollbar-bg-l2`, `--dsw-alias-scrollbar-hover-l2` | полоса прокрутки |
| `--ds-ease-in-out` | все переходы |

### Отступы и метрики

Горизонтальный отступ берём у ядра — его задаёт `@deepseek-ai/dsh-client-ui-sidebar`,
который остаётся на месте:

```css
padding-inline: var(--dsh-sidebar-inline-padding);
```

Это единственный способ совпасть по вертикали с кнопкой «Новая сессия» над нами.
Своё число здесь — гарантированный рассинхрон при любой правке ядра.

Метрики списка `--dsh-session-list-edge-inset`,
`--dsh-session-list-scrollbar-offset`, `--dsh-session-list-scrollbar-width`
задавал заменяемый модуль, поэтому вместе с ним они исчезнут. Объявляем свои
под тем же смыслом и с теми же значениями, с префиксом `--dsc-`.

### Типографика

Наследуем от документа. Заголовок сессии — обычный вес, размер как в ядровой
строке; возраст — на ступень мельче и вторичным цветом. Своих шрифтов и
`font-family` не вводим, кроме `--ds-font-family-code`, если понадобится
показать идентификатор.

### Классы

Префикс `dsc-` у каждого класса без исключений. Стили живут в общем документе
рядом с чужими; класс без префикса однажды перекрасит чужую разметку, и искать
причину будут долго.

### Accessibility

- Заголовки разделов — `button` с `aria-expanded`, не `div` с обработчиком.
- Список сессий — навигация с клавиатуры: стрелки, Enter открывает, F2
  переименовывает, Escape отменяет.
- Меню `...` открывается с клавиатуры и закрывается по Escape с возвратом
  фокуса на кнопку.
- Индикатор `running` дублируется текстом для чтения с экрана, а не только
  цветом.
- Переименование по месту — обычное поле с меткой, а не `contenteditable`.

## Components And States

### Компоненты

| Компонент | Назначение |
|---|---|
| `SessionList` | корень блока: поиск, разделы, прокрутка |
| `PinnedGroup` | закреплённые, плоско, в порядке закрепления |
| `WorkspaceGroup` | папка и её сессии |
| `SessionRow` | строка: заголовок, возраст, индикатор, меню |
| `RowMenu` | закрепить/открепить, переименовать, ответвить, скрыть, архив |
| `CollapsedSection` | «Скрытые», «Архив» и периоды внутри архива |
| `ArchiveViewer` | расшифровка архивной сессии, только чтение |
| `HeroWorkspacePicker` | выбор папки на пустом экране беседы |
| `SettingsCard` | карточка в «Настройки → Плагины» |

### Состояния

| Состояние | Что показываем |
|---|---|
| `loading` | скелет из трёх строк, без текста «Загрузка» |
| `empty` — нет папок | приглашение создать первую папку с кнопкой |
| `empty` — папка пуста | одна строка пояснения внутри папки |
| `empty` — поиск без результата | «Ничего не найдено» и подсказка искать по содержимому |
| `error` — операция не удалась | сообщение в самой строке цветом ошибки, действие не откатывается молча |
| `error` — настройки недоступны | закрепление и скрытие отключены, панель работает как обычный список; причина написана |
| `unreadable` — журнал раннего формата | расшифровка объясняет, что ядро отказывается читать, а не сообщает о пустоте |
| `success` | без всплывающих уведомлений: результат виден в самом списке |

**Статус снимка настроек важнее значения.** При `unavailable` карточка не рисует
пустую форму, которая с виду работает: она пишет, что пространство настроек
хосту неизвестно. Проверяем статус, а не значение.

### Формы, валидация и действия

- **Переименование:** двойной клик по заголовку → поле в строке. Enter
  сохраняет, Escape отменяет, потеря фокуса сохраняет. Пустое имя не
  сохраняется, строка остаётся в правке.
- **Скрытие:** обратимо, наше. Возврат — из раздела «Скрытые».
- **Архив:** пункт меню ведёт в ядровый архив и **необратим**. Спрашиваем
  подтверждение и прямо пишем, что вернуть нельзя. Это единственное действие
  плагина с подтверждением.

## User Flows

1. **Закрепить нужное.** Меню строки → «Закрепить». Сессия уходит в группу
   сверху. Переживает перезагрузку, другой браузер и другое устройство.
2. **Найти старое.** Поиск в шапке блока: по заголовкам и по содержимому
   диалогов. Результат — плоский список со сниппетами.
4. **Убрать лишнее, не потеряв.** Меню → «Скрыть». Раздел «Скрытые» внизу,
   возврат одним нажатием.
5. **Назвать понятно.** Двойной клик по заголовку, правка на месте.
6. **Начать работу в проекте.** Кнопка «Новая сессия» ядра и выбор папки на
   пустом экране беседы продолжают работать — это обязательства замены, а не
   наша функциональность.

## Do / Don't

**Do**

- Брать горизонтальные отступы из `--dsh-sidebar-inline-padding`.
- Регистрировать в слоты только через `ctx.slots.inject(name, cb)`.
- Показывать отказ операции в интерфейсе, а не в консоли.
- Держать половину «сервис» без React и без нашей логики.
- Проверять статус снимка настроек перед отрисовкой формы.

**Don't**

- Не искать чужие узлы через `querySelector` и не клонировать ядровые кнопки:
  это ровно тот способ, который у нас уже ломается в других плагинах.
- Не заводить свой раздел в боковом списке настроек — только карточка.
- Не использовать литеральные цвета и свои значения отступов панели.
- Не строить скрытие поверх ядрового архива: он необратим.
- Не предлагать перенос диалога между папками: модель этого не допускает.
- Не показывать всплывающих уведомлений об успехе.
- Не разворачивать разделы «Скрытые» и «Архив» по умолчанию.

## Locked Design Decisions

- **2026-09-05 — заменяем блок, а не дополняем.** Слот `sidebar.workspaces`
  объявлен ядром как `kind: "single"`, второго регистранта не бывает, другого
  слота в теле панели нет. Пересмотр — если ядро объявит слот списочным или
  добавит точки расширения внутри списка.
- **2026-09-05 — две независимые половины.** Сервис `uiWorkspace` стоит в
  обязательном `inject` у `dsh-client-ui-sidebar` и `dsh-client-ui-conversation`,
  поэтому отказ нашей вёрстки не должен уносить приложение. Пересмотр — если
  ядро перестанет требовать этот сервис.
- **2026-09-05 — закрепление общее на всю панель,** не внутри папки. Решение
  владельца. Пересмотр — если папок станет столько, что закреплённые начнут
  смешивать проекты.
- **2026-09-05 — своё скрытие вместо ядрового архива.**
  `WorkspaceRegistry.archiveSession` только добавляет, метода возврата в API нет,
  раздела архива в интерфейсе нет вовсе. Пересмотр — если ядро добавит возврат.
- **2026-09-05 — настройки карточкой `settings.plugin.item`,** без своего
  раздела. Пересмотр — только по явной просьбе владельца.
- **2026-09-05 — переноса между папками не будет.** Рабочая папка — это каталог на хосте, а членство сессии выводится из её рабочего каталога: `attachSession` в реестре отвергает сессию, чей `cwd` не совпадает с путём папки. Перенести диалог в другую папку нельзя ни из клиента, ни из серверной половины — это не пробел в API, а устройство модели. Именно поэтому такого пункта нет и в ядровой панели.
  Пересмотр — только если ядро перестанет выводить членство из рабочего
  каталога. Обнаружено проверкой на песочнице: пункт меню возвращал
  `workspace/move-invalid: the session is not accounted`.
- **2026-09-07 — расшифровку архива готовит серверная половина.** Со стороны
  браузера архив не читается: `session/follow` требует потокового переносчика,
  `session/page` отвечает «failed to observe session», а окно истории
  поднимается только для текущей сессии. Запертое решение «своих маршрутов нет»
  снято осознанно и только для чтения. Пересмотр — если ядро откроет чтение
  чужого журнала с клиента.
- **2026-09-07 — плагин везёт только английский.** Переводы поставляет
  отдельный языковой плагин и занимает то же пространство настроек раньше нас.
  Собственный русский словарь ронял регистрацию, а вместе с ней всю половину
  «интерфейс». Регистрация словаря защищена отдельно от остального.
- **2026-09-07 — текущая сессия не прячется никогда,** даже пустая. Иначе
  исчезает строка, в которую человек как раз собирается писать.
- **2026-09-07 — архив разбит по календарным периодам,** а не по «минус
  столько-то часов»: человек мыслит «сегодня» и «на этой неделе». Свёрнутый
  период не рисуется — это же снимает вопрос отрисовки сотен строк.
- **2026-09-05 — автоназвание диалогов вне рамок первой версии.** Требует
  вызовов модели и денег; переименование по месту закрывает ту же боль даром.
  Пересмотр — после обкатки, отдельной задачей.
  **Changed 2026-09-07:** посылка оказалась неверной. Первая фраза человека уже
  лежит в журнале сессии, который мы и так читаем для расшифровки, поэтому
  подпись выводится без единого вызова модели и без расходов. Решение заменено
  следующим.
- **2026-09-07 — подпись выводится из первой фразы человека,** когда
  сохранённого названия нет. Порядок: сохранённое название, затем выведенное,
  затем `displayTitle` ядра. Ручное переименование всегда главнее и вытесняет
  выведенное немедленно. Мы ничего не пишем в журнал и не вызываем `rename` за
  человека: выведенное имя — только подпись в нашей панели. Спрашиваем по
  одному разу за загрузку страницы и только за строки, которые сейчас
  нарисованы; свёрнутый раздел не порождает запросов. Пересмотр — если чтение
  журналов окажется дорогим на больших установках.
- **2026-09-07 — метки вместо переноса между папками.** Перенос невозможен по
  устройству ядра (решение от 2026-09-05 остаётся в силе), но настоящая
  потребность — собрать вместе то, что относится к одной теме. Метка живёт
  только в нашем пространстве настроек, ядро о ней не знает, на членство в
  папке и на архив она не влияет. Опустевшая метка удаляется сама. Пересмотр —
  если ядро заведёт собственную ось группировки.
- **2026-09-07 — окно быстрого перехода ничего не меняет.** По `Alt+K`
  открывается поиск с переходом, и только он: ни закрепления, ни архивации, ни
  переименования. Окно поверх интерфейса — не место для необратимых действий.
  Сочетание — `Alt`, а не `Ctrl`. Проверка свободы в ядре была неполной: я
  смотрел только обработчики DSH и не учёл сам браузер, который держит `Ctrl+K`
  за собой и странице его не отдаёт. Alt свободен и в ядре, и у соседних
  плагинов (заняты `Alt+S` и `Alt+стрелки`). Буква сверяется и по кириллической
  раскладке. Пересмотр — если сочетание займёт ядро или браузер.
- **2026-09-07 — Markdown для выгрузки собирает серверная половина.** Тот же
  маршрут расшифровки с `format=md`. Логика сборки одна на всех и покрыта
  тестами; браузерная половина живёт отдельным бандлом и не может импортировать
  модули пакета, поэтому вторая копия логики в ней означала бы расхождение.
  Пересмотр — если бандл научится подтягивать модули пакета.
- **2026-09-13 — дескрипторный доступ к sessionPersistence.** В версиях DSH 0.1.5-rc.2+
  ядро перешло на дескрипторный контракт: метод `persistence.open(id, 'read')`
  и `handle.read(0, undefined)`. Методы `resolveLog` и `readStoredLog` удалены
  из ядра. Серверная половина адаптирована под `open` с сохранением fallback-ветки
  для старых сред и обязательным освобождением дескриптора.
- **2026-09-13 — чипы-фильтры в окне быстрого перехода Alt+K.** Над поисковой
  строкой окна быстрого перехода добавлены интерактивные фильтры: Все (All),
  Закреплённые (Pinned), Метки (Tags), Архив (Archived). Фильтр сужает список
  кандидатов до применения поискового запроса.
- **2026-09-13 — бейджи активности и числа ходов.** В строке сессии выводится
  компактный ненавязчивый индикатор количества ходов (`turnsCount`), помогающий
  быстро ориентироваться в длине бесед без открытия сессии.
- **2026-09-13 — дублирование сессии без истории (Fork Clean).** В меню сессии
  добавлен пункт дублирования настроек: создаётся чистый диалог в той же
  рабочей папке с сохранением рабочей конфигурации, но с пустым контекстом.
- **2026-09-13 — пакетные действия над сессиями.** При множественном выборе
  диалогов (через Shift/клик) доступна панель массовых действий: пакетное

- **2026-09-17 — значок размера сессии в строке (#39).** Лента чата ядра
  `0.1.6-alpha.1` не виртуализирована: сессия на 5 458 событий подвесила вкладку
  во время 8-минутного хода, сервер при этом работал штатно. Порог считается по
  событиям (жёлтый 1 500, красный 3 000, меняются в карточке), байты — только в
  подсказке. Уровень вычисляет хост по живым порогам; при смене порогов клиент
  спрашивает заново. На значке число событий текстом — смысл не держится на
  одном цвете. Нет данных о размере — нет значка, не угадываем. Пересмотр — когда
  ядро виртуализирует ленту.
- **2026-09-17 — «Продолжить в новой сессии» кладёт черновик, а не отправляет (#40).**
  Человек обязан увидеть и поправить текст до отправки. `setDraft` доступен только
  изнутри сессии, а панель живёт в корневой области, поэтому черновик паркуется в
  хранилище на `window` по идентификатору новой сессии и забирается компонентом в
  `conversation.input.dock` ровно один раз. Хранилище на `window`, а не в замыкании:
  клиентское дерево применяется дважды. Пересмотр — если ядро даст корневой доступ
  к вводу сессии.
- **2026-09-17 — выдержка по умолчанию, пересказ моделью по явному нажатию (#41).**
  Решение владельца: оба варианта. Выдержка бесплатна и мгновенна; пересказ тратит
  токены и выключен, пока не заданы провайдер и модель. Вход модели ограничен
  бюджетом от конца расшифровки, итог честно помечает неполноту. Внедрённый
  контекст (`<system-reminder>`, `<agentmemory_context>`, снимки runtime) в
  выдержку и пересказ не попадает.
- **2026-09-17 — монолитная архитектура клиентского бандла lib/client.js (#37).**
  Файл `lib/client.js` содержит 2 476 строк, превышая условный ориентир preflight (600 строк).
  Принято архитектурное решение сохранить файл цельным:
  1. Плагины DSH являются zero-build модулями, загружаемыми веб-рантаймом напрямую как единый
     ES-модуль из `lib/client.js` без сборщиков (webpack/vite/rollup) на стороне рантайма.
  2. Разделение на относительные импорты нарушает браузерную загрузку через cordis loader.
  3. Суммарный упакованный размер пакета составляет ~63 КБ (строгий лимит платформы — 256 КБ).
  4. Аналогичная архитектурная норма соблюдается во всех официальных плагинах со сложным UI
     (`dsh-kanban` — 4 392 строки, `dsh-goal` — 4 384 строки, `dsh-cron` — 4 092 строки).
  Пересмотр — если ядро DSH внедрит поддержку бандлинга клиентских подмодулей для веб-плагинов.
